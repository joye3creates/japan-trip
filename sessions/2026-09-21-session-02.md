## Decisions

### Yours

**1. Session logs arrive as a file at a fixed hour, not as chat output.**
You said you did not want the log reproduced in conversation. That is a workflow
decision with teeth: it turned an ad-hoc habit into a scheduled routine, and it
forced the format to stand alone as a document rather than lean on surrounding chat.

*Consequence:* the convention was written into `CLAUDE.md`, so a future session
that starts cold still honours it.

**2. You uploaded the source files yourself after my copy was blocked.**
Copying uploaded files into the repo is blocked on my side by a provenance check.
Rather than leave the archive incomplete, you added them directly. That single act
is what made the pipeline reproducible — without the workbook in the repo, every
future run would have depended on a file only you hold.

**3. GitHub as the store, no local clone.**
You chose not to download anything, treating the repo as the source of truth.
Reasonable, and it shaped the advice: the useful answer became "download the ZIP
from the Code button" rather than a terminal workflow you do not want yet.

**4. The woodblock brief — six specifications and one image.**
Minimal lines, ukiyo-e woodcut, neutral colour, paper feel with light texture,
interactive, zoomable to dig deeper. Plus a reference image of a Japanese survey map.

*This is the most instructive decision of the session.* Six specs and one image
was enough to land close on the first attempt. It is documented in `STYLE_BRIEF.md`
as the worked example, alongside the four things the brief did **not** settle,
which I had to choose alone: typefaces, how the route reads against land, what
"dig deeper" concretely means, and whether to keep prefecture borders.

**5. Asking for a realistic map, and for a 3D asset specifically.**
The ask was for real geography rather than the abstract diagram. You suggested
downloading a 3D asset. That framing is what prompted me to re-test what this
container can actually reach — and the answer had changed since session 01.

### The assistant's

**1. Conventions go in the repo, not only in the scheduled prompt.**
A routine prompt is invisible to a session that starts fresh. `CLAUDE.md` loads
automatically. *Rejected alternative:* relying on the trigger prompt alone, which
would have silently stopped working the first time the routine was recreated.

**2. Scripts made location-independent, not merely repointed.**
The minimum fix was changing one hardcoded path. Instead both scripts now resolve
paths against their own file location, so the pipeline runs from any directory on
any machine. *Reasoning:* the readme had been telling you to edit a constant
before running. Instructions that say "edit this line first" are a bug.

**3. Reproducibility verified by checksum, not assumed.**
Captured `md5sum` of the outputs before switching sources, then compared after.
Both matched. Claiming reproducibility without testing it would have been the
easy path and worthless.

**4. The unused Nagano booking kept as a first-class record.**
It would have been simpler to drop a hotel you never slept in. Instead it carries
`status: "not used"` and draws on the map as a hollow dashed square.

*Reasoning:* a place that was planned and abandoned is real information about the
trip. It also strengthened the day 10 Matsumoto question — a hotel booked in
Nagano prefecture means that region was genuinely in the plan, which makes the
"Matsumoto the city" reading likelier than "Matsumoto Kiyoshi the drugstore".

**5. Real coastlines by cloning geodata, reversing session 01's decision.**
Session 01 rejected hand-drawing a Japan silhouette as too likely to look
amateurish, and settled for an abstract diagram. This session re-tested the
network and found that while geocoding APIs stay blocked, **git clone works**. So
real prefecture geometry came in over git.

*The lesson worth recording:* a constraint accepted in one session was not
re-examined until you pushed on it. The environment had not changed; my map of it
had simply never been completed.

**6. Douglas-Peucker at roughly a tenth of the points, and 1,068 islands dropped.**
80,370 points to 6,830, at 115 KB. *Reasoning specific to this brief:* a
generalised coastline is not a loss of fidelity in a woodblock survey sheet, it is
the correct register. The style forgives, and rewards, simplification that a
satellite aesthetic would not.

**7. Woodblock misregistration as a deliberate artefact.**
Land fills sit roughly one pixel off their own keylines. Real woodblock prints
misregister when the colour block and the outline block do not align. Cheap to
implement, and it does more for authenticity than any texture.

**8. "Dig deeper" answered as progressive disclosure by zoom.**
Outlines and route at rest; place marks past 1.5x; names past 2.6x; transit nodes
only past 3.4x. *Rejected alternative:* a click-through drill-down with explicit
levels, which would have needed chrome the sheet has no room for.

**9. A separate artifact, not a replacement.**
You called it an experiment. Two live URLs make comparison possible; overwriting
would have destroyed the thing being compared.

**10. Recommended against Figma for now.**
Figma is readable through a connector, so it is a genuine option. But a pixel
mockup gets reproduced literally, including its accidents, while tokens and
references produce a system that extends to unbuilt screens.

### On roadblock 17, because it is good case-study material

The screenshot showed garbled marks in each day cell. Two plausible causes: the
webfont had not loaded and a fallback was rendering badly, or the layout was wrong.

Probing the DOM said the layout was *correct* — a 14 by 74 pixel box holding two
characters, exactly as intended. That seemed to exonerate the layout. But a
screenshot at three times scale showed the two glyphs printed at the same
position, in a box the right size.

So the box was right and the advance was zero. Vertical writing mode depends on
the font's vertical advance metrics, and the fallback in use had none. The fix was
to stop depending on those metrics at all.

**Two lessons.** A DOM probe can confirm a box and still miss what is drawn inside
it, so the pixels are the authority. And a feature that works only when a webfont
has loaded is fragile even when the webfont usually loads.

the most productive thing in the brief.**

*Produced:* nothing directly, because the blocker was an account link rather than
software. But it is a good example of a reasonable offer aimed at the wrong

> extra day instead of nagayno"

*Produced:* three bookings parsed, and the unused Nagano night recorded as a

**On getting at the output**

*Produced:* the file sent directly, plus instructions. *Worth recording* because

**The meta-question**

> "let me know what would be the best way of conveying the visual style that I

*The question was better than it looks*, because it separated style from
