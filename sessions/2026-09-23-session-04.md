## Decisions

### The owner's

- **Stills, not trimmed video, is left to the assistant**, with a requirement to
  say which. Stills were used.
- **Carry the name patterns inside the script**, because `names.local.txt` will
  not exist on Netlify.
- **Allowlist exactly two strings**, the portfolio and Bluesky handles.
- **Ask before touching `robots.txt`.** Left as it is.

### The assistant's

- **Names are stored as salted hashes, not plain text.** Carrying them in the
  script and never committing them are both rules here; hashing satisfies both
  as far as `git grep` goes. Rejected: plain patterns (commits the names).
  Stated plainly in the file: a dictionary of first names reverses these hashes,
  so it is obscurity, not secrecy, and the repository still needs to stay private.
- **Names match inside longer words**, so a handle glued to a surname is caught.
  That is also why the allowlist is needed at all.
- **Binaries are scanned for names and emails only**, in their printable strings
  and PNG text chunks. Phone and reference shapes turn up by chance in random
  bytes. Rejected: skipping binaries (image metadata can carry an author).
- **The big number is derived, not hand-written.** The first figure in the bold
  phrase of "The number:", or its first sentence when there is no bold. Spelled
  numbers become digits. Rejected: a per-day override table in code, which would
  put editorial text somewhere nobody reads it.
- **Unknown field labels fail the build** as well as missing ones, so a typo does
  not silently fold a field into the one above it.
- **No `BUILDING_IN_PUBLIC.md` entry for today.** The log page reads that file,
  so a Day 4 entry would publish Day 4 at launch, which the brief ruled out.

### What changed

- **`**Headline:**` field**, optional and matched by prefix like the rest. It must
  read `<figure> — <label>`, and a label over six words fails the build. When it
  is absent the old inference runs and the build prints a warning naming the day.
  Added to Days 1–3: `~₹50,000 — shopping never totalled on the summary`,
  `6,830 — map points, down from 80,370`, `89% — marks squeezed left on linear axis`.
- **Only linked assets are published.** The build collects every `assets/…` that
  a staged page links from `src` or `href`, fails if any are missing, and clears
  `site/assets/` before writing so a file the page no longer uses loses its URL.
  Five files came out of `site/assets/`; three stills, 1.2 MB, remain.
- **The gate reports text files and binaries separately**, lists each binary, and
  says that text drawn into their pixels needs human review.

### Decisions (the assistant's)

- **Day 1 reads `~₹50,000`**, with the tilde, because the entry says "about".
  Rejected: a bare figure, which would state more precision than the source has.
- **An over-long label fails rather than truncates.** Cutting a stated label
  would be inferring again.
- **`site/assets/` is wiped on every build.** Netlify deploys the committed tree
  plus the build output, so a stale file left there would still get a URL.
