## Decisions

### The owner's

- **One chat for the daily loop, another for changes, a third for logs.** Reasoning:
  keep the build conversation uncluttered. Rejected: one session for everything.
  Reversed later the same day, see below.
- **Retire the third session.** Once the 23:59 routine was found to already write
  both files, the separate logging session was duplicating it and would have
  opened a competing pull request the same night. Rejected: editing the routine
  to write only half.
- **"Building in public" is not a claim to make on day four.** Reasoning: it
  describes a practice, and four days does not earn it. Rejected: the terminal
  panel that performed the practice rather than stating a fact.
- **The story is not the tooling.** "I came back from a trip and could not answer
  how it was" replaced every framing offered, including the assistant's
  data-visualisation pitch. Rejected: leading with the AI angle, which was
  demoted to a chip.
- **Two font sizes, one for the headline and one for everything else.** Reasoning:
  six sizes looked fussy. Differentiation moved to weight and colour.
- **No em dashes, numerals over words.** A standing style rule, applied to the copy.
- **Paper treatment, but without the border.** Reasoning: the keyline made the
  panel an object sitting on the card rather than part of it.
- **Plus Jakarta over Poppins for the headline**, after seeing both, on
  compactness. Hind Siliguri made the same card 111px taller.

### The assistant's

- **Re-shoot all three stills, not the two that were badly framed.** Reasoning:
  the font fault was shared by all three, and fixing two would have left one
  card in a different typeface. Cost: one extra capture. Rejected: shipping the
  route map unchanged, which had been called good an hour earlier.
- **Serve the fonts from disk rather than disabling certificate checks.**
  `curl` trusts the proxy's CA and Chromium does not, so the stylesheet and its
  woff2 files are fetched with curl and returned through `page.route`.
  Rejected: `--ignore-certificate-errors`, which would have worked and would
  have meant turning off TLS verification to take a screenshot.
- **The loop's zoom is camera, not interaction.** The clock view has no zoom, so
  a push-in was done by cropping recorded frames rather than by driving a
  feature that does not exist. Rejected: animating the SVG viewBox, which would
  have implied a control the page does not have.
- **MP4 rather than GIF, with the numbers rather than the assertion.** The same
  5.8 seconds is 226 KB as MP4 and 2.25 MB as a GIF. Rejected: the GIF the
  owner originally asked for; the measurement made the case.
- **Build the kasumi version before rejecting it.** It put a straight edge back
  on all four sides, which was the thing being removed. Rejected on sight of the
  render rather than on argument.
- **`status.json` carries no timestamp.** With one it would change on every
  rebuild and churn the diff on days when nothing happened. The day number is
  the freshness signal. Verified byte-identical across consecutive builds.
- **CORS scoped to `/status.json` alone**, not to the site.

## Roadblocks

**Every screenshot in the project had the wrong typography, and nothing said so.**
Chromium in this container does not trust the agent proxy's certificate
authority, so `fonts.googleapis.com` failed with `ERR_CERT_AUTHORITY_INVALID`
and every page fell back to Georgia. The renders looked plausible, which is why
it survived three sessions. Found by checking the request log, not the picture.
Cost: roughly 40 minutes, three stills re-shot. Fix: fetch with curl, serve
through `page.route`, then read `document.fonts` to confirm what actually loaded.

**The session 04 PR shipped a broken headline on two days of three.** The big
number was inferred from whichever phrase was bolded, so Day 1 read "2" with a
twelve-word label and buried a ₹50,000 reconciliation error. Cost: one review
round. Fix: an explicit `**Headline:**` field, and the build fails rather than
truncating a long label.

**4.6 MB of unreferenced media was staged for publication**, including two screen
recordings nobody had reviewed for that context. Fix: copy only what a page links.

**`mask-image` with a radial gradient feathered only the corners**, because at
118% the fade point sits outside the box at the edge midpoints. Fix: two linear
gradient masks composited with `mask-composite: intersect`.

**The capture script silently used the wrong font stylesheet**, returning an
empty `document.fonts` list, because it cached the first CSS it fetched. Caught
by the check added after the Georgia bug, which is the check earning its keep
within the hour.

**The git proxy refused a branch deletion.** No fix; the branch was left in
place, which turned out to be correct since it held the only other copy of a
draft that had not been merged yet.

## Prompts and briefs

> "I want like changes and all. So I probably start a new Claude uh, code chat and go there because I want to keep this chat for the purpose of just uh, working on things every day."

Produced the three-session split. Left open which session owned which files, which
took two more exchanges to settle and one retirement to correct.

> "Send me the prompt first. It was written before the GitHub and Netlify work existed"

The assistant's request, not the owner's, and the most useful move of the morning.
Half the prepared prompt was already done and one line would have overwritten four
working pages.

> "keep on flagging these personal information things"

A standing instruction from an earlier session, load-bearing all day. It is why
the stills were opened and looked at rather than trusted to the gate.

> "That okay keep the japanese text and the shopping things. Those were later design decisions we took so let's keep the original"

From an earlier session, and the reason `assets/README.md` had a claim about
stripping Japanese script that had quietly stopped being true. Corrected today.

> "I think this whole thing like building it in public and all is I don't want to showcase it too much like that because I'm just starting it out."

Killed the strongest-performing of the three card directions. Correctly.

> "you can also think of it in a story way that basically I went to Japan last year and I loved the trip and I did not post any pictures because there was so much to post and so much to talk about"

The single most useful thing said today. Every line of card copy was rewritten
from it. The assistant had been pitching data visualisation; the actual story is
better and was sitting in the owner's head unasked-for.

> "I do want to change the font because this does not look that great right now. And uh, also, I'm not sure about the font size. So just let me know what font sizes you have used."

Produced the collapse from six sizes to two. The request was for information and
the answer was a diagnosis: listing the six sizes was enough to show the problem.

> "reduce the feather a bit more. Like, uh, I think the gradient effect is becoming too much."

9% and 11% down to 4% and 5%.

> "No, let's go ahead with whatever font you chose earlier that looked more compact."

A reversal of the owner's own choice from twenty minutes before, made on seeing it
rendered. Hind Siliguri made the card 543px against 432px for the same content.

> "start building what you have to build and then after you're done with all this, just let me know how I should go ahead and put all this in Framer."

Produced `status.json` and the final component. Note the shift: after a day of
step-by-step approval, this is the first instruction that hands over a block of
work whole.
